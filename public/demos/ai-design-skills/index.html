THE MISSING PIECE

The code compiles. The design does not.

AI coding tools ship working features with generic layouts, borrowed fonts and spacing that means nothing. Ask for a landing page and you get a page. Ask for a good one and you get whatever the model remembers.

The gap was never the code. It was a design system the model could follow. These skills put one in place, one markdown file at a time.

WHAT YOU GET

Two skills. One way of working.

Each skill is a self-contained folder with a single SKILL.md. Install the ones you need.

Pages that argue, not just render

landing-page-design runs intake before pixels: page structure, conversion copy, then the visual system, in that order. The output has a job to do.

Figma files you can actually edit

figma-designer builds real structure: spacing, radius and color variables, named text styles, auto layout, components with every state, and a Foundations frame that tracks the tokens.

One file per skill, any tool

Claude Code, Cursor, Codex, Windsurf and Cline all read the same markdown. Nothing to port, nothing to rewrite when you switch editors.

Yours to fork

Every design value, fonts, colors, spacing, radius, motion, lives in one section near the bottom of each file. Fork the repo, edit that section, and the rest of the skill follows.

HOW IT WORKS

Install, ask, ship.

STEP 01

Install

Run one npx command. Pick the skills you want and the agents that should get them. Skills land in .claude/skills/ or .agents/skills/.

STEP 02

Ask in plain language

“Build a landing page for my app.” The skill handles intake, structure, copy and the visual system. You review the result, not the rules.

STEP 03

Ship, then update

Output follows one design system end to end. Run npx skills update later to pull changes from the repo.

FAQ

Questions, answered plainly.

Is this just a prompt pack?

No. Each skill is one markdown rules file with two halves: a strategy section that decides what the page says, and a visual system that decides how it looks. The model follows the file, not a vibe.

Which tools does it work with?

Anything that reads a markdown rules file: Claude Code, Cursor, Codex, Windsurf, Cline. On Claude.ai, download the SKILL.md and upload it to a Project or attach it to a chat.

Do I have to install both skills?

No. Install only what you need: npx skills add elayadesign/ai-design-skills --skill landing-page-design.

Can I change the design values?

Yes. Fonts, colors, spacing, radius and motion live in one section near the bottom of each file. Fork the repo, edit that section, and the rest of the skill follows automatically.

What if my site already exists?

Use the companion skill, redesign-skill. It diagnoses an existing site and defers to these rules for every concrete value.

Can I audit a live page?

SlopScan checks a live page against the same rules and hands your agent a fix prompt.

Does it need an account or send data anywhere?

No account. The skills are local markdown files that live in your project. The repo itself runs CI that validates every SKILL.md on each push.

What is the license?

MIT. Use it, fork it, ship what you build with it. No attribution needed.
