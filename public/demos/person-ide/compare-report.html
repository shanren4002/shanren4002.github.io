文档中讲解的是 Python 函数参数的类别，共列出以下 7 类：

四大基础类别：

  1. 位置参数（Positional Arguments）
  2. 关键字参数（Keyword Arguments）
  3. 默认参数（Default Arguments）
  4. 可变参数（*args 和 **kwargs）

进阶类别（Python 3 新增）： 5. 仅位置参数（Positional-only，Python 3.8+，用 / 标记） 6. 仅关键字参数（Keyword-only，用 * 标记） 7. 完整参数顺序（终极版，如 def func(pos1, pos2, /, normal, *, kw_only)）

标准参数顺序为：位置参数 → 默认参数 → *args → 仅关键字参数 → **kwargs。
