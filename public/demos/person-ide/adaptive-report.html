答案

文档中 Python 函数参数的分类方式如下：

基础四类：

  1. 位置参数（Positional Arguments）——按顺序传值
  2. 关键字参数（Keyword Arguments）——用 参数名=值 传递，顺序无关
  3. 默认参数（Default Arguments）——定义时求值一次，所有调用共享同一对象
  4. 可变参数（Variable-length Arguments）——*args 打包多余位置参数为元组，**kwargs 打包多余关键字参数为字典

Python 3.8+ 扩展两类： 5. 仅位置参数（Positional-only）——用 / 标记，/ 之前的参数只能用位置传递 6. 仅关键字参数（Keyword-only）——用 * 标记，* 之后的参数只能用关键字传递

完整参数顺序规则： 位置参数 → 默认参数 → *args → 仅关键字参数 → **kwargs，违反顺序会引发语法错误。

inspect 视角的分类（param.kind 枚举）： POSITIONAL_ONLY、POSITIONAL_OR_KEYWORD、VAR_POSITIONAL、KEYWORD_ONLY、VAR_KEYWORD 五类。
