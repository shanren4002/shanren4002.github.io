答案

文档中 Python 函数参数的分类方式如下：

四类基础参数类别：

  1. 位置参数（Positional Arguments）——按定义顺序绑定
  2. 关键字参数（Keyword Arguments）——用参数名=值传递，顺序无关
  3. 默认参数（Default Arguments）——定义时求值一次，需注意可变默认值陷阱
  4. 可变参数（Variable-length Arguments）——*args 打包为元组，**kwargs 打包为字典

Python 3.8+ 进阶分类： 5. 仅位置参数（Positional-only，用 / 标记）——/ 之前的参数只能用位置传递 6. 仅关键字参数（Keyword-only，用 * 标记）——* 之后的参数只能用关键字传递

完整参数定义顺序： 位置参数 → 默认参数 → *args → 仅关键字参数 → **kwargs

此外，文档还提到可通过 inspect 模块的 param.kind 在运行时区分参数种类（如 POSITIONAL_ONLY、VAR_POSITIONAL、KEYWORD_ONLY 等）。
